About TruthGuard

TruthGuard is an AI-assisted web platform designed to help users identify fake or misleading news by verifying content against trusted sources.

🎯 Project Objective

The primary objective of TruthGuard is to combat the spread of misinformation by providing users with an easy-to-use tool that evaluates news credibility in real time.

🌍 Social Impact

Fake news can influence public opinion, cause panic, and spread false narratives. TruthGuard encourages responsible information sharing by promoting verification before belief.

🛠️ Technology Stack

  • HTML, CSS, JavaScript
  • NewsAPI for real-time news verification
  • AI-based text classification
  • Modern responsive UI design

👩‍💻 Developer

This project was developed as part of an academic and learning initiative to explore frontend development, API integration, and socially impactful applications.
